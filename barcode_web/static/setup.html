Phone setup

Checking this phone…

Testing whether this phone trusts the laptop's certificate.

Open scanner

  1. Download the certificate

    Chrome may warn that the file is downloaded over an insecure connection. Choose Keep: it is only this laptop's public certificate.

    Download certificate

  2. Install it as a CA certificate

    Open Settings and search for CA certificate (often Security → Encryption & credentials → Install a certificate → CA certificate). Choose Install anyway, then pick the downloaded file.

    Do not choose “VPN & app user certificate” or “Wi-Fi certificate”. Chrome ignores those, and the warning stays.

  3. Come back to this page

    The box at the top turns green within a few seconds. If it stays orange, restart Chrome and check again.

  1. Download the profile in Safari

    This page must be open in Safari, not another browser. Tap the button and choose Allow.

    Download certificate

  2. Install the profile

    Open Settings → General → VPN & Device Management (or “Profile Downloaded” at the top of Settings). Tap the mkcert profile and install it.

  3. Turn on full trust

    Open Settings → General → About → Certificate Trust Settings and switch on the mkcert certificate. Without this step Safari still shows the warning.

  4. Come back to this page

    The box at the top turns green within a few seconds.

Only install the certificate from your own laptop. A trusted certificate authority can vouch for other sites on this phone, so the laptop keeps its private key secret and never serves it. Remove the profile in Settings when you stop using the scanner.
