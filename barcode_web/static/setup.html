First-use phone setup

The camera requires a trusted HTTPS connection to your laptop. Install this laptop's local certificate once on each phone.

Download laptop CA certificate

Android / Chrome

  1. Download the certificate above.
  2. In Settings, search for “Install a certificate”. Choose CA certificate (usually Security → Encryption & credentials → Install a certificate). Select the downloaded file and confirm. Menu names vary by phone.
  3. Open the current HTTPS phone link from the laptop receiver in Chrome. Press Start camera and allow camera access.

iPhone / Safari

  1. Open this setup page in Safari and download the certificate. Allow the configuration profile.
  2. Open Settings → General → VPN & Device Management (or Profile Downloaded). Install the mkcert profile.
  3. Open Settings → General → About → Certificate Trust Settings. Enable full trust for this mkcert root.
  4. Open the current HTTPS phone link from the laptop receiver in Safari. Press Start camera and allow camera access.

Only install the certificate from your own laptop. A trusted CA can issue certificates your phone accepts; protect the laptop's private keys. You can remove the certificate from Settings when you stop using this scanner.

This HTTP page is only for certificate setup. Camera scanning and sending barcode text use HTTPS. The server never serves private keys.
